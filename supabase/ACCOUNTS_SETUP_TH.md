# ระบบบัญชีผู้ใช้ (Accounts) - คู่มือย่อ

## ภาพรวม
ตอนนี้ทีมงานเข้าระบบด้วย **username** ไม่ต้องใช้อีเมล และ Boss สามารถ
เพิ่ม ลบ ตั้งรหัสผ่าน และเปลี่ยน username ได้เองจากหน้า **Accounts** ในหลังบ้าน

เบื้องหลัง: Supabase Auth ต้องมีอีเมลเสมอ ระบบจึงเก็บ username เป็น
`ชื่อผู้ใช้@accounts.headstartphuket.com` โดยอัตโนมัติ ไม่มีการส่งอีเมลไปที่นั้น
เป็นเพียงตัวระบุตัวตนภายในเท่านั้น รหัสผ่านยังคงถูกเข้ารหัสโดย Supabase ตามมาตรฐานเดิม

## สิทธิ์
- **Owner**: เห็นแถบ Accounts และจัดการผู้ใช้ได้ทั้งหมด
- **Staff**: ใช้งานระบบอีเวนต์ได้ตามปกติ แต่ไม่เห็นแถบ Accounts

บัญชี `events.city@headstartphuket.com` ถูกตั้งเป็น Owner ไว้แล้ว

## สิ่งที่ต้องทำเป็นอันดับแรก
1. เข้าระบบด้วยบัญชีเดิม (`events.city@headstartphuket.com`)
2. ไปที่ **Accounts** แล้วกด **Password** ที่บัญชีของตัวเอง เพื่อ**เปลี่ยนรหัสผ่านใหม่**
   (สำคัญมาก เพราะรหัสเดิมมีคนอื่นรู้อยู่)
3. กด **Add account** สร้างบัญชีให้ทีมงานทีละคน ตั้ง username และรหัสผ่านให้เขา
   แล้วส่งให้เขาโดยตรง เลือกสิทธิ์เป็น **Staff**
4. บัญชี `tassapolbn@hotmail.com` ที่ไม่เคยใช้งาน แนะนำให้ลบทิ้งหรือเปลี่ยนรหัส

## ส่วนหลังบ้าน
Edge Function ชื่อ `admin-users` ติดตั้งบนโปรเจกต์ Supabase เรียบร้อยแล้ว
เป็นตัวจัดการผู้ใช้โดยใช้ service key ที่อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น
ไม่มี service key อยู่ในเว็บไซต์ และเฉพาะบัญชี Owner ที่ล็อกอินแล้วเท่านั้นที่เรียกใช้ได้

โค้ดอยู่ที่ `supabase/functions/admin-users/index.ts`
หากต้องแก้ไขในอนาคต แก้ไฟล์นี้แล้ว deploy ใหม่
