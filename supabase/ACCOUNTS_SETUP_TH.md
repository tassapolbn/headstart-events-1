# บัญชีผู้ใช้และแบบประเมิน

บัญชีใหม่เข้าสู่ระบบด้วย Username และ Password โดยไม่ต้องมีอีเมลจริง
บัญชีเดิมที่ใช้อีเมลยังคงเข้าสู่ระบบได้ตามปกติ

## การจัดการบัญชี
เข้า Settings > Account > Manage accounts ด้วยบัญชี Admin
เพิ่มบัญชี แก้ชื่อที่แสดง Username รหัสผ่าน และเลือกสิทธิ์ Admin หรือ Staff ได้
Admin จัดการบัญชีได้ทั้งหมด ส่วน Staff ใช้งานแบบฟอร์มและอีเวนต์ แต่เข้าจัดการบัญชีไม่ได้
ระบบเก็บสิทธิ์ Admin เป็น `owner` เพื่อรองรับข้อมูลเดิม
ห้ามลบบัญชีที่กำลังใช้งาน และห้ามลดสิทธิ์ Admin คนสุดท้าย
บัญชีที่ยังไม่มีสิทธิ์จะไม่ได้รับสิทธิ์ Admin อัตโนมัติ

## แบบประเมิน
ใน Form Builder เลือก Rating scale สำหรับคะแนน 1 ถึง 5 หรือ 1 ถึง 10
เลือก Evaluation / Survey สำหรับข้อความระดับความพึงพอใจ
มีข้อความเริ่มต้นภาษาไทยและอังกฤษ สามารถเพิ่ม ลบ เรียงลำดับ และแก้ข้อความได้
เปิด Required เมื่อต้องการบังคับตอบ หรือใช้ Conditional logic เพื่อแสดงตามคำตอบก่อนหน้า
คำตอบเก็บในข้อมูล Registration เดิมและส่งออก CSV หรือ Excel ได้

## การติดตั้งจาก Pull Request
1. Deploy Edge Function `admin-users` จากโค้ดใน Pull Request ก่อนเผยแพร่ frontend เพราะการแก้บัญชีใช้การอัปเดตครั้งเดียว
2. ตรวจว่ามีบัญชี Admin ที่กำหนด `app_metadata.role = owner` ไว้แล้ว การติดตั้งนี้ไม่เลื่อนสิทธิ์ให้บัญชีใดอัตโนมัติ
3. Build และเผยแพร่ frontend ตามกระบวนการเดิม ไม่มีการเปลี่ยน schema ฐานข้อมูล
4. ทดสอบด้วยบัญชี Admin และ Staff ที่ได้รับอนุญาต รวมถึงการส่งแบบประเมินจริงบน staging

## การตรวจสอบในเครื่อง
`npm ci`
`npm run build`
`node tests/accounts-survey.mjs`

การทดสอบบัญชีใช้ Auth API จำลอง ไม่สร้างหรือลบบัญชีจริง
